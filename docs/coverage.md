- **Bound surface**: NRI's functions (every function-pointer field of the interface tables NRI
  fills, and every flat export) that PrismNRI's own code calls, and the fields of NRI's native
  structs that PrismNRI's idiomatic API reaches: a struct the public API takes or returns is
  exposed with all its fields; a struct the binding builds from its own managed forms counts
  only the fields binding code reads or writes; a data layout no NRI function takes (indirect
  arguments, instances, query results) counts through its public type. The raw tables and
  `NriApi` reach everything and are not counted. Read from the built assemblies (IL and PDB).
- **Test coverage**: the lines of PrismNRI's hand-written C# that the test suite executes,
  child processes included; the generated L0 (`dotnet/Native`) is not counted. It depends on
  what the machine can run: CI's software adapters skip about half the tests.
