## Added
- SharpNRI.AgilitySDK: copies the Agility SDK runtime at NRI's version into `AgilitySDK\`, build error on another version; debug layer in Debug builds
- Device creation refuses an NRI library or SharpNRI.Descs of another NRI version (`INVALID_SDK`, both versions named)
- `TryCreateSharedFence`, `TryCreateSharedBinaryFence`, `TryCreateSharedBuffer`, `TryCreateSharedTexture`
- With SharpNRI.AgilitySDK, a missing `AgilitySDK\D3D12Core.dll` is an error, not the inbox runtime
- Windows: `NRI.dll` needs no Visual C++ runtime (static C runtime)

## Fixed
- SharpNRI's dependency on SharpNRI.Descs, and SharpNRI.Testing's on SharpNRI, are exact versions
- Package description named macOS arm64 and "Alpha"

## Breaking changes
- SharpNRI.Descs versioned by NRI: 191.0.0-beta.1, new only when the descs change
