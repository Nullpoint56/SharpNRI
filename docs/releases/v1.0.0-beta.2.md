**NRI v191**

## Changes

### Added
- Published on NuGet.org: `dotnet add package SharpNRI --prerelease`. The packages carry a readme.

### Fixed
- `WriteShaderGroupIdentifiers` with a group range past the pipeline's groups ended the process on D3D12 and Vulkan, also with NRI validation on; validation now refuses the range with `INVALID_ARGUMENT`.
- Vulkan pipeline-statistics query pools on a device with mesh shaders but without mesh-shader queries drew a validation error at creation and reported a query size two counters too large.
- `ENABLE_DRAW_PARAMETERS_EMULATION` on Vulkan: indirect draws with the plain `DrawDesc` / `DrawIndexedDesc` records were refused. The flag is D3D12 and Metal only and now has no effect on Vulkan, so it can be set on every backend.
- Documentation: `SwapChainBits.LATEST_READY` with `VSYNC` does not cap rendering at the refresh rate; the display shows the newest ready image at each vblank.

## Verified
NVIDIA GeForce RTX 4070 SUPER (Vulkan, D3D12) at 42797cb ([coverage](https://github.com/Nullpoint56/SharpNRI/blob/v1.0.0-beta.2/docs/coverage.md)); Microsoft Basic Render Driver (WARP, D3D12) and Mesa llvmpipe (lavapipe, Vulkan) at 42797cb. The release commit adds packaging metadata and documentation only.
