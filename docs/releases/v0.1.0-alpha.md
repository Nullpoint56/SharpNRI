**NRI v190**

## Changes

### Added
- C# binding over NRI: Vulkan, D3D12 and NONE. One class per NRI object, one method per command, one class per extension; the generated native layer (`PrismNRI.Descs`) usable without a device.
- Packages: `PrismNRI`, `PrismNRI.Descs`, `PrismNRI.Testing`, `PrismNRI.Native.Upscalers`, `PrismNRI.Native.Agility`; native payloads for win-x64, linux-x64 and osx-arm64 (Vulkan through MoltenVK).
- `NriQueue.UploadData`, `CreateAccelerationStructureVK` / `CreateAccelerationStructureD3D12`, `NriHandle`, the flat exports on `Nri`.

## Verified
At a130f8e ([CI](https://github.com/Nullpoint56/PrismNRI/actions/runs/38542262834)): Microsoft Basic Render Driver (WARP, D3D12), Mesa llvmpipe (lavapipe, Vulkan), Apple Paravirtual device (MoltenVK, Vulkan).
