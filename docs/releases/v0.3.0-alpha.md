**NRI v190**

## Changes

### Changed
- `NriDescriptorSet` is a `readonly struct` (handle + pool, equal by handle).

### Added
- `AllocateDescriptorSets(..., Span<NriDescriptorSet>)`: per-frame set allocation without managed allocations. A whole frame (pool and allocator reset, set allocation and writes, recording, submit, wait, acquire, present) is held to zero managed bytes and zero host allocations.

## Breaking changes
- `NriDescriptorSet` is a value type: no `null`, and copies compare equal.
