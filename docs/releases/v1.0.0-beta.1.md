## Added
- C# binding over NRI: Vulkan, D3D12, NONE; every NRI object, command and extension
- Packages: `SharpNRI`, `SharpNRI.Descs` (descs and enums, no native code), `SharpNRI.Testing` (validated headless devices), `SharpNRI.Native.Upscalers` (NIS, FSR, XeSS)
- Zero allocation per frame on the managed heap
- D3D12 on the Agility SDK from `Microsoft.Direct3D.D3D12`

## Fixed
- Vulkan without tessellation, geometry, task, mesh or ray tracing shaders: `ALL_SHADERS` / `ALL` stages refused by the validation layer
- FSR on Vulkan: runtime check named FidelityFX SDK 1.1.4's `amd_fidelityfx_vk.dll`

## Breaking changes
- From PrismNRI 0.4.0-alpha: package ids, assemblies and namespaces `SharpNRI*`; environment variables `SHARPNRI_*`; MSBuild properties `SharpNRI*`
- No Agility package: reference `Microsoft.Direct3D.D3D12`
